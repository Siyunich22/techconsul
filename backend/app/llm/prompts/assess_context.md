# Контекст проекта (общий для всех пунктов отчёта)

## Подтверждённый паспорт проекта
Значения паспорта подтверждены экспертом. Метки `[S..]` у значений — источники: на них можно ссылаться в выводах без дополнительного поиска.

$passport

## Документы проекта (обзор для навигации)
Обзор показывает, какие документы есть и где в них что лежит. На обзор **не ссылайся**: чтобы сослаться на факт из документа, найди фрагмент через `search_project_docs` — метку источника выдаст инструмент. Ищи целенаправленно, по разделам и фактам из обзора. Если нужного документа в обзоре нет, не трать обращения на его поиск — отметь недостаток данных.

$documents
