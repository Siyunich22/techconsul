4. Информационные пункты (`source:`/`render:` в YAML) — собираются из данных проекта без ИИ.
5. Оркестратор: порядок по `depends_on`, параллельно N пунктов, выводы и замечания получают результаты своих пунктов; сбой пункта — `failed`, прогон продолжается.

7. Вкладка «Оценка»: запуск с предупреждением о стоимости, прогресс по разделам в реальном времени, результат пункта с источниками, «Пересобрать пункт».
